# Actividad práctica de CSS básico


Artículo IEEE a una columna sobre control de cambios con Git.


Autor: Pan Lijian Wong  
Asignatura: Programación Orientada al Usuario  
Institución: Universidad Centroamericana José Simeón Cañas


## Abrir el trabajo


Descarga o clona el repositorio y abre `index.html` en un navegador, manteniendo `style.css` en la misma carpeta. No requiere instalación ni conexión para visualizar el artículo.


## Archivos principales


- `index.html`: artículo con resumen, palabras clave, secciones I a V, tabla y cinco referencias oficiales citadas en orden.
- `style.css`: estilos externos, con selectores de etiqueta, clase e id y la pseudo-clase `:hover`.
- `evidencia-git.txt`: comandos y salida de la prueba local que respalda los resultados. Es material de apoyo.


Se omite la figura porque es opcional. No se usan frameworks, hojas externas de terceros, JavaScript, flex, grid, position, float ni clear.
